# 🧑‍🏫 1. What is Destructuring?

**Destructuring** means taking values out of an object or array and putting them into variables in a clean way.

Instead of:

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer"
};

const name = user.name;
const age = user.age;
const role = user.role;
```

We can write:

```js
const { name, age, role } = user;
```

Now JavaScript creates:

```js
name // "Nayeem"
age  // 25
role // "Developer"
```

### 🧠 Mental model

Think:

```text
Object
   ↓
Destructure
   ↓
Take out specific properties
   ↓
Variables
```

# 2. Object Destructuring

Let's start with a simple object:

```js
const user = {
  name: "Nayeem",
  age: 25,
  city: "Dhaka"
};
```

Without destructuring:

```js
const name = user.name;
const age = user.age;
const city = user.city;
```

With destructuring:

```js
const { name, age, city } = user;
```

Much cleaner.

---

# 3. Important Rule: Object Destructuring Uses Property Names

Consider:

```js
const user = {
  name: "Nayeem",
  age: 25
};
```

This:

```js
const { name, age } = user;
```

works because `name` and `age` match the object's property names.

But:

```js
const { username } = user;
```

doesn't find anything.

So:

```js
console.log(username);
```

gives:

```text
undefined
```

### 🧠 Remember

For objects:

> **Destructuring is based on property names, not position.**

---

# 4. Renaming Variables

Sometimes you don't want the variable to have the same name as the property.

Suppose:

```js
const user = {
  name: "Nayeem",
  age: 25
};
```

You can do:

```js
const { name: userName, age: userAge } = user;
```

Now:

```js
console.log(userName);
console.log(userAge);
```

Output:

```text
Nayeem
25
```

### Read this syntax carefully:

```js
const { name: userName } = user;
```

It means:

```text
object property → variable name
name            → userName
```

It does **not** mean you're changing the object.

The original object is still:

```js
{
  name: "Nayeem",
  age: 25
}
```

---

# 5. Default Values

What happens if the property doesn't exist?

```js
const user = {
  name: "Nayeem"
};

const { name, age } = user;

console.log(age);
```

Result:

```text
undefined
```

You can provide a default:

```js
const { name, age = 18 } = user;
```

Now:

```js
console.log(age);
```

Output:

```text
18
```

### Important

The default is used when the property is `undefined`.

# 6. Array Destructuring

Now arrays are different.

Consider:

```js
const colors = ["red", "green", "blue"];
```

Without destructuring:

```js
const first = colors[0];
const second = colors[1];
const third = colors[2];
```

With destructuring:

```js
const [first, second, third] = colors;
```

Now:

```js
first  // "red"
second // "green"
third  // "blue"
```

### 🧠 Important difference

Object:

```js
const { name } = user;
```

uses **property names**.

Array:

```js
const [first] = colors;
```

uses **position**.

---

# 7. Array Destructuring Is Position-Based

Given:

```js
const numbers = [10, 20, 30];
```

```js
const [a, b, c] = numbers;
```

means:

```text
a → numbers[0] → 10
b → numbers[1] → 20
c → numbers[2] → 30
```

So:

```js
console.log(a);
console.log(b);
console.log(c);
```

Output:

```text
10
20
30
```

---

# 8. Skip Array Values

You don't have to take every value.

```js
const numbers = [10, 20, 30, 40];
```

Suppose we only want `10` and `30`.

```js
const [first, , third] = numbers;
```

Now:

```js
first // 10
third // 30
```

The empty space:

```js
[ first, , third ]
          ↑
```

means:

> Skip this value.

---

# 9. Rest Pattern in Array Destructuring

Suppose:

```js
const numbers = [10, 20, 30, 40, 50];
```

We want the first number and all remaining numbers.

```js
const [first, ...rest] = numbers;
```

Now:

```js
first // 10
rest  // [20, 30, 40, 50]
```

### 🧠 Remember

```js
...rest
```

collects the remaining values.

---

# 10. Swapping Variables

One of the classic JavaScript destructuring examples:

```js
let a = 10;
let b = 20;
```

Normally, swapping requires a temporary variable.

But destructuring lets us do:

```js
[a, b] = [b, a];
```

Now:

```js
a // 20
b // 10
```

This is a common interview example.

# 11. Nested Object Destructuring

Now let's get into the interesting part.

Consider:

```js
const user = {
  name: "Nayeem",
  age: 25,
  address: {
    city: "Dhaka",
    country: "Bangladesh"
  }
};
```

Without destructuring:

```js
const city = user.address.city;
const country = user.address.country;
```

With nested destructuring:

```js
const {
  address: { city, country }
} = user;
```

Now:

```js
console.log(city);
console.log(country);
```

Output:

```text
Dhaka
Bangladesh
```

### 🧠 Mental model

```text
user
 ↓
address
 ↓
city
country
```

Destructuring follows the same structure.

# 13. Nested Array Destructuring

Now let's focus on what you specifically asked for.

Consider:

```js
const numbers = [
  [10, 20],
  [30, 40],
  [50, 60]
];
```

We have:

```text
numbers
  ↓
[10, 20]
[30, 40]
[50, 60]
```

We can destructure:

```js
const [
  [a, b],
  [c, d],
  [e, f]
] = numbers;
```

Now:

```js
a // 10
b // 20

c // 30
d // 40

e // 50
f // 60
```

### 🧠 Look at the structure

Original:

```js
[
  [10, 20],
  [30, 40]
]
```

Destructuring:

```js
[
  [a, b],
  [c, d]
]
```

The structure must match.

# 14. Nested Array Destructuring With Objects

```js
const users = [

  },
  {
    name: "Rahim",
    age: 30
```

```js
const [{ name, age }] = users;
```

```text
users
 ↓
[0]

object

name / age
```

# 17. Destructuring Function Parameters

This is **very important for real-world JavaScript**.

Suppose:

```js
function displayUser(user) {
  console.log(user.name);
  console.log(user.age);
}
```

We can destructure directly in the parameter:

```js
function displayUser({ name, age }) {
  console.log(name);
  console.log(age);
}
```

Then:

```js
const user = {
  name: "Nayeem",
  age: 25
};

displayUser(user);
```

Output:

```text
Nayeem
25
```

### 🧠 Why is this useful?

Instead of:

```js
user.name
user.age
user.role
```

inside the function, you immediately receive the properties you need.

# 18. Destructuring in Array Methods

This is extremely useful.

Given:

```js
const users = [
  { name: "Nayeem", age: 25 },
  { name: "Rahim", age: 30 },
  { name: "Karim", age: 22 }
];
```

Without destructuring:

```js
users.map(user => user.name);
```

With destructuring:

```js
users.map(({ name }) => name);
```

Result:

```js
["Nayeem", "Rahim", "Karim"]
```

Similarly:

```js
users.filter(({ age }) => age >= 25);
```

This reads very naturally:

> Filter users whose age is at least 25.

---

# 19. Destructuring in `for...of`

You can also destructure while looping.

```js
const users = [
  { name: "Nayeem", age: 25 },
  { name: "Rahim", age: 30 }
];

for (const { name, age } of users) {
  console.log(name, age);
}
```

Output:

```text
Nayeem 25
Rahim 30
```

This is very common in modern JavaScript.

# 20. Destructuring `Object.entries()`

Remember:

```js
const user = {
  name: "Nayeem",
  age: 25
};
```

`Object.entries(user)` gives:

```js
[
  ["name", "Nayeem"],
  ["age", 25]
]
```

We can destructure each pair:

```js
for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

This:

```js
const [key, value]
```

is **array destructuring**.

# 21. A Real-World API Example

Imagine an API returns:

```js
const response = {

    user: {
```

Without destructuring:

```js
const name = response.data.user.name;
const email = response.data.user.email;
const skills = response.data.user.skills;
```

With destructuring:

```js
const {
  data: {
    user: { name, email, skills }
  }
```

Now:

```js
console.log(name);
console.log(email);
console.log(skills);
```

Much cleaner.

# 22. Important: Destructuring Doesn't Change the Original Data

Consider:

```js
const user = {
  name: "Nayeem",
  age: 25
};

const { name } = user;
```

You now have:

```text
user.name → "Nayeem"
name      → "Nayeem"
```

The original object hasn't been changed.

Destructuring simply extracts values into variables.

---

# 23. Common Mistake #1

Don't confuse these:

### Object

```js
const { name } = user;
```

### Array

```js
const [name] = users;
```

Object → `{}`

Array → `[]`

---

# 24. Common Mistake #2

Remember that arrays use **position**.

```js
const colors = ["red", "green", "blue"];

const [a, b] = colors;
```

Result:

```text
a → red
b → green
```

Not:

```text
a → blue
b → red
```

---

# 25. Common Mistake #3 — Nested Structure Must Match

Given:

```js
const data = [
  [10, 20],
  [30, 40]
];
```

Correct:

```js
const [[a, b], [c, d]] = data;
```

The nesting matches:

```text
Array
 ├── Array
 │    ├── 10
 │    └── 20
 │
 └── Array
      ├── 30
      └── 40
```

# 🧠 Your Destructuring Cheat Sheet

### Object

```js
const { name, age } = user;
```

### Rename

```js
const { name: userName } = user;
```

### Default

```js
const { age = 18 } = user;
```

### Array

```js
const [first, second] = numbers;
```

### Skip

```js
const [first, , third] = numbers;
```

### Rest

```js
const [first, ...rest] = numbers;
```

### Nested object

```js
const {
  address: { city }
} = user;
```

### Nested array

```js
const [[a, b], [c, d]] = numbers;
```

### Array containing objects

```js
const [{ name }] = users;
```

### Object containing array

```js
const { skills: [firstSkill] } = user;
```

### Array → object → array

```js
const [
  {
    skills: [skill1, skill2]
  }
] = users;
```

### Function parameter

```js
function greet({ name, age }) {
  console.log(name, age);
}
```
