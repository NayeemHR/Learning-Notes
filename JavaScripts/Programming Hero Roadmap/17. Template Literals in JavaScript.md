# 🧑‍🏫 Template Literals in JavaScript

## 1. What Problem Do Template Literals Solve?

Suppose we have:

```js
const name = "Nayeem";
const age = 25;
```

We want to create:

```text
My name is Nayeem and I am 25 years old.
```

The old way was:

```js
const message = "My name is " + name + " and I am " + age + " years old.";
```

It works, but when the sentence becomes longer, it gets difficult to read.

Template literals make this much cleaner.

```js
const message = `My name is ${name} and I am ${age} years old.`;
```

Output:

```text
My name is Nayeem and I am 25 years old.
```

---

# 2. What Is a Template Literal?

A template literal is a string created using **backticks**:

```js
`Hello World`
```

Not:

```js
"Hello World"
```

and not:

```js
'Hello World'
```

The important character is:

```text
`
```

Usually found near the `1` key on a keyboard.

---

# 3. Expression Interpolation

This is the most important concept.

Inside a template literal, we can insert JavaScript expressions using:

```js
${expression}
```

For example:

```js
const name = "Nayeem";

console.log(`Hello ${name}`);
```

Output:

```text
Hello Nayeem
```

This process is called **interpolation**.

### 🧠 Mental model

Think:

```text
Template literal
      ↓
   `Hello ${name}`
             ↓
       JavaScript expression
             ↓
          "Nayeem"
             ↓
      "Hello Nayeem"
```

---

# 4. What Is an Expression?

An **expression** is something JavaScript can evaluate to a value.

For example:

```js
name
```

is an expression.

So is:

```js
age + 5
```

So is:

```js
price * quantity
```

So is:

```js
age >= 18
```

And even:

```js
user.name
```

Therefore, all of these can be used inside `${}`.

---

# 5. Arithmetic Inside `${}`

You don't have to insert only variables.

You can perform calculations:

```js
const price = 100;
const quantity = 3;

console.log(`Total price: ${price * quantity}`);
```

Output:

```text
Total price: 300
```

Another example:

```js
const price = 1000;
const discount = 100;

console.log(`Final price: ${price - discount}`);
```

Output:

```text
Final price: 900
```

### 🧠 Key idea

`${}` can contain a **JavaScript expression**, not just a variable.

---

# 6. Expressions With Functions

You can even call a function inside interpolation.

```js
function greet(name) {
  return `Hello, ${name}!`;
}

const user = "Nayeem";

console.log(`${greet(user)}`);
```

Output:

```text
Hello, Nayeem!
```

You can also do:

```js
console.log(`Message: ${greet("Nayeem")}`);
```

---

# 7. Expressions With Conditions

You can use a ternary operator inside `${}`.

```js
const age = 25;

const message = `You are ${age >= 18 ? "an adult" : "a minor"}.`;

console.log(message);
```

Output:

```text
You are an adult.
```

This is extremely useful in UI development.

For example:

```js
const isLoggedIn = true;

const message = `Status: ${isLoggedIn ? "Logged in" : "Logged out"}`;
```

Output:

```text
Status: Logged in
```

---

# 8. Working With Objects

Suppose:

```js
const user = {
  name: "Nayeem",
  role: "WordPress Developer"
};
```

We can do:

```js
const message = `Name: ${user.name}, Role: ${user.role}`;

console.log(message);
```

Output:

```text
Name: Nayeem, Role: WordPress Developer
```

Notice:

```js
${user.name}
```

is an expression.

---

# 9. Working With Arrays

Suppose:

```js
const skills = ["HTML", "CSS", "JavaScript"];
```

We can use:

```js
console.log(`My skills: ${skills.join(", ")}`);
```

Output:

```text
My skills: HTML, CSS, JavaScript
```

We used a method inside interpolation:

```js
${skills.join(", ")}
```

---

# 10. Multi-Line Strings

This is another major advantage of template literals.

Without template literals:

```js
const message = "Hello\nWelcome to JavaScript\nKeep learning!";
```

With template literals:

```js
const message = `Hello
Welcome to JavaScript
Keep learning!`;
```

Output:

```text
Hello
Welcome to JavaScript
Keep learning!
```

You don't need `\n`.

# 13. Template Literals + Functions

Let's make it reusable:

```js
function getProductSummary(product) {
  const total = product.price * product.quantity;

  return `
Product: ${product.name}
Price: ${product.price}
Quantity: ${product.quantity}
Total: ${total}
`;
}
```

Now:

```js
const product = {
  name: "Laptop",
  price: 80000,
  quantity: 2
};

console.log(getProductSummary(product));
```

Output:

```text
Product: Laptop
Price: 80000
Quantity: 2
Total: 160000
```

```text

   +
Object
   +
Expression
   +
Template literal
```

# 14. Template Literals in HTML

This is especially important for you as a frontend/WordPress developer.

Suppose we want to generate HTML dynamically.

```js
const user = {
  name: "Nayeem",
  role: "WordPress Developer"
};

const html = `
  <div class="user-card">
    <h2>${user.name}</h2>
    <p>${user.role}</p>
  </div>
`;
```

Now `html` contains:

```html
<div class="user-card">
  <h2>Nayeem</h2>
  <p>WordPress Developer</p>
</div>
```

This technique is commonly used when JavaScript needs to generate dynamic HTML.

---

# 15. Template Literals + Arrays

Now imagine:

```js
const products = [
  {
    name: "Laptop",
    price: 80000
  },
  {
    name: "Mouse",
    price: 1500
  },
  {
    name: "Keyboard",
    price: 3000
  }
];
```

We can generate HTML for each product:

```js
const html = products.map(product => `
  <div class="product">
    <h2>${product.name}</h2>
    <p>Price: ${product.price}</p>
  </div>
`).join("");
```

### 🧠 Follow the flow:

```text
products
   ↓
map()
   ↓
each product
   ↓
template literal
   ↓
HTML string
   ↓
join()
   ↓
one HTML string
```

This is a **very common frontend pattern**.

# 16. Nested Expressions

You can even combine multiple operations:

```js
const price = 1000;
const quantity = 3;
const discount = 10;

const total = price * quantity;
const finalPrice = total - (total * discount / 100);

console.log(`
Price: ${price}
Quantity: ${quantity}
Discount: ${discount}%
Final Price: ${finalPrice}
`);
```

Output:

```text
Price: 1000
Quantity: 3
Discount: 10%
Final Price: 2700
```

# 18. Common Mistake #1

❌ Wrong:

```js
const name = "Nayeem";

console.log("Hello ${name}");
```

Output:

```text
Hello ${name}
```

Why?

Because `" "` creates a normal string.

Use backticks:

```js
console.log(`Hello ${name}`);
```

Output:

```text
Hello Nayeem
```

---

# 19. Common Mistake #2

Don't forget the `$`.

❌

```js
`Hello {name}`
```

❌

```js
`Hello (name)`
```

✅

```js
`Hello ${name}`
```

The correct syntax is:

```text
${expression}
```

---

# 20. Common Mistake #3 — `${}` Outside Template Literals

This won't work:

```js
console.log(${name});
```

`${}` is specifically used **inside a template literal**.

Correct:

```js
console.log(`${name}`);
```

---

# 🧠 Interview Answer

If an interviewer asks:

> **What are template literals in JavaScript?**

A good answer:

> Template literals are strings created using backticks. They allow string interpolation using `${}` expressions, support multi-line strings, and make it easier to build dynamic strings.

If they ask:

> **What is expression interpolation?**

Say:

> Expression interpolation is the ability to evaluate a JavaScript expression inside `${}` within a template literal and insert its resulting value into the string.
