# 🌳 What is DOM in JavaScript?

**DOM = Document Object Model**

In simple words:

> **The DOM is a JavaScript representation of an HTML document that allows JavaScript to read, change, add, or remove HTML elements.**

Think of it like this:

```text
HTML
  ↓
Browser reads HTML
  ↓
Creates DOM
  ↓
JavaScript can interact with DOM
```

---

## 1. Start with HTML

Suppose we have:

```html
<h1>Hello World</h1>
<p>Welcome to my website</p>
<button>Click Me</button>
```

The browser converts this HTML into a **tree-like structure**:

```text
Document
│
└── html
    │
    ├── h1
    │   └── "Hello World"
    │
    ├── p
    │   └── "Welcome to my website"
    │
    └── button
        └── "Click Me"
```

This structure is called the **DOM tree**.

# 2. Why do we need the DOM?

JavaScript by itself doesn't directly modify the HTML source file.

Instead:

```text
JavaScript
     ↓
    DOM
     ↓
Web page
```

For example, we can change:

```html
<h1>Hello World</h1>
```

into:

```html
<h1>Hello Nayeem</h1>
```

using JavaScript.

```js
const heading = document.querySelector("h1");

heading.textContent = "Hello Nayeem";
```

The page changes immediately.

---

# 3. What is `document`?

You'll see this constantly when working with the DOM:

```js
document
```

`document` represents the current HTML document/page.

For example:

```js
console.log(document);
```

You can use `document` to find and manipulate elements.

---

# 4. Selecting HTML Elements

This is the first major DOM skill.

## `querySelector()`

HTML:

```html
<h1 class="title">Hello World</h1>
```

JavaScript:

```js
const heading = document.querySelector(".title");
```

Now:

```js
heading
```

refers to that `<h1>` element.

### Think:

```text
document
   ↓
querySelector()
   ↓
HTML element
```

---

# 5. Selecting by ID

HTML:

```html
<h1 id="title">Hello World</h1>
```

JavaScript:

```js
const heading = document.querySelector("#title");
```

Or:

```js
const heading = document.getElementById("title");
```

Both can select the element.

---

# 6. Changing Text

Once we have an element:

```js
const heading = document.querySelector("#title");
```

We can change its text:

```js
heading.textContent = "Hello Nayeem";
```

Before:

```text
Hello World
```

After:

```text
Hello Nayeem
```

---

# 7. Changing HTML

We can also use:

```js
element.innerHTML
```

Example:

```js
const box = document.querySelector(".box");

box.innerHTML = "<strong>Hello</strong>";
```

The browser interprets the string as HTML.

### Difference

```js
textContent
```

treats content as text.

```js
innerHTML
```

parses content as HTML.

For example:

```js
heading.textContent = "<b>Hello</b>";
```

displays:

```text
<b>Hello</b>
```

But:

```js
heading.innerHTML = "<b>Hello</b>";
```

renders:

**Hello**

---

# 8. Changing CSS

Suppose:

```html
<h1 id="title">Hello World</h1>
```

We can change the style:

```js
const heading = document.querySelector("#title");

heading.style.color = "red";
heading.style.fontSize = "40px";
```

The browser now displays a red, 40px heading.

However, in real projects, it's usually better to manipulate **classes** rather than lots of inline styles.

---

# 9. Working with Classes

HTML:

```html
<div class="box">Hello</div>
```

JavaScript:

```js
const box = document.querySelector(".box");
```

### Add class

```js
box.classList.add("active");
```

### Remove class

```js
box.classList.remove("active");
```

### Toggle class

```js
box.classList.toggle("active");
```

### Check class

```js
box.classList.contains("active");
```

This is extremely common in frontend development.

---

# 10. Creating Elements

The DOM isn't only about changing existing HTML.

JavaScript can **create new elements**.

```js
const paragraph = document.createElement("p");
```

Then:

```js
paragraph.textContent = "Hello from JavaScript";
```

Then add it to the page:

```js
document.body.appendChild(paragraph);
```

Now the page contains:

```html
<p>Hello from JavaScript</p>
```

---

# 11. Removing Elements

Suppose:

```html
<p id="message">Hello</p>
```

We can remove it:

```js
const message = document.querySelector("#message");

message.remove();
```

The paragraph disappears from the page.

---

# 12. DOM Events ⭐

This is where JavaScript becomes interactive.

HTML:

```html
<button id="btn">Click Me</button>
```

JavaScript:

```js
const button = document.querySelector("#btn");

button.addEventListener("click", function () {
    console.log("Button clicked!");
});
```

When the user clicks:

```text
User clicks button
       ↓
click event
       ↓
JavaScript function runs
```

This is called **event handling**.

---

# 13. Real Example

Let's build a tiny counter.

### HTML

```html
<h1 id="count">0</h1>
<button id="increase">Increase</button>
```

### JavaScript

```js
let count = 0;

const countElement = document.querySelector("#count");
const button = document.querySelector("#increase");

button.addEventListener("click", function () {
    count++;

    countElement.textContent = count;
});
```

When the user clicks:

```text
0
↓
1
↓
2
↓
3
↓
4
```

The DOM is being updated every time.

# 🧠 The Most Important DOM Mental Model

Remember these four steps:

```text
1. SELECT
      ↓
2. CHANGE
      ↓
3. LISTEN
      ↓
4. CREATE/REMOVE
```

### SELECT

```js
const button = document.querySelector("#button");
```

### CHANGE

```js
button.textContent = "Clicked";
```

### LISTEN

```js
button.addEventListener("click", () => {});
```

### CREATE

```js
const p = document.createElement("p");
```

### REMOVE

```js
p.remove();
```
