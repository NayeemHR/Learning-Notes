# 🧠 Lesson 1: Variables in JavaScript

A **variable** is a named container used to store data.

Think of it like a labeled box:

```js
let name = "Nayeem";
```

Here:

* `name` → variable name
* `"Nayeem"` → value
* `let` → keyword used to create the variable
* `=` → assignment operator

You can think:

> **Variable = a named place where we keep a value so we can use it later.**

---

## 1. Creating a Variable

JavaScript gives us three keywords for declaring variables:

```js
var
let
const
```

Example:

```js
let age = 25;
const country = "Bangladesh";
var score = 100;
```

However, in **modern JavaScript**, you should generally use:

```js
let
const
```

and avoid `var` unless you specifically need its older behavior.

---

# 2. `let`

Use `let` when the value **can change**.

```js
let age = 25;

age = 26;

console.log(age);
```

Output:

```text
26
```

The important thing is that `age` was declared once, but its value was changed.

### Another example

```js
let username = "Nayeem";

username = "Rahim";

console.log(username);
```

Output:

```text
Rahim
```

---

# 3. `const`

Use `const` when you **don't want to reassign the variable**.

```js
const country = "Bangladesh";
```

You cannot do:

```js
country = "India";
```

This causes an error because a `const` variable cannot be reassigned.

### Think of it this way:

```js
let age = 25;        // Can change
const country = "BD"; // Cannot be reassigned
```

A common modern JavaScript practice is:

> **Use `const` by default. Use `let` when you know the value needs to change.**

---

# 4. What about `var`?

You may see older JavaScript code like:

```js
var name = "Nayeem";
```

`var` is the older way of declaring variables.

The biggest difference you'll eventually need to understand is **scope**.

For example:

```js
if (true) {
    var x = 10;
}

console.log(x);
```

`var` is **function-scoped**, not block-scoped.

But:

```js
if (true) {
    let y = 20;
}

console.log(y);
```

This produces an error because `let` is **block-scoped**.

We'll study **scope** properly later. For now, remember:

> **Modern JavaScript → prefer `let` and `const`.**

---

# 5. Variables Can Store Different Types of Data

A variable doesn't only store numbers.

### String

```js
let name = "Nayeem";
```

### Number

```js
let age = 25;
```

### Boolean

```js
let isDeveloper = true;
```

### Array

```js
let skills = ["HTML", "CSS", "JavaScript"];
```

### Object

```js
let user = {
    name: "Nayeem",
    age: 25
};
```

So variables can hold many different kinds of values.

---

# 6. Variable Naming Rules

You can write:

```js
let firstName = "Nayeem";
let age = 25;
let userName = "Nayeem";
```

But you **cannot** write:

```js
let 123name = "Nayeem"; // ❌
```

Variable names cannot start with a number.

You also shouldn't use spaces:

```js
let first name = "Nayeem"; // ❌
```

Instead use camelCase:

```js
let firstName = "Nayeem"; // ✅
```

### Common naming convention

JavaScript developers commonly use **camelCase**:

```js
let firstName;
let lastName;
let phoneNumber;
let totalPrice;
let userEmail;
```

---

# 7. JavaScript is Dynamically Typed

This is an **important interview concept**.

You don't have to specify the data type when declaring a variable.

For example:

```js
let value = 10;
```

Later:

```js
value = "Hello";
```

This is allowed.

The variable's value changed from a **number** to a **string**.

That's because JavaScript is **dynamically typed**.

Compare this conceptually with languages where you'd explicitly declare types:

```text
int age = 25;
```

JavaScript doesn't require that:

```js
let age = 25;
```

---

# 8. Declaration vs Assignment

This distinction is important.

### Declaration

Creating the variable:

```js
let age;
```

At this point, the variable exists but has no assigned value.

Its value is:

```js
undefined
```

### Assignment

Giving it a value:

```js
age = 25;
```

### Declaration + Assignment

You can do both at once:

```js
let age = 25;
```

---

# 9. Reassignment

With `let`:

```js
let score = 50;

score = 100;
```

This is called **reassignment**.

But:

```js
const score = 50;

score = 100; // ❌ Error
```

Because `const` doesn't allow reassignment.

---

# 🎯 Interview Question

**Interviewer:** What is a variable in JavaScript?

A good answer:

> **"A variable is a named container used to store a value in JavaScript. We can declare variables using `let`, `const`, or `var`. In modern JavaScript, we generally use `const` when a variable won't be reassigned and `let` when its value needs to change."**
