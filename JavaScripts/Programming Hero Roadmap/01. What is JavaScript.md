### What is JavaScript?

**JavaScript is a high-level, interpreted programming language primarily used to make web pages interactive and dynamic.**

Think of a website as three main layers:

* **HTML** → Structure — *What is on the page?*
* **CSS** → Styling — *How does it look?*
* **JavaScript** → Behavior — *How does it work?*

For example:

```html
<button onclick="alert('Hello!')">Click Me</button>
```

Here, HTML creates the button, while JavaScript makes something happen when you click it.

### What can JavaScript do?

JavaScript can:

* Change HTML content and CSS
* Handle user interactions like clicks and forms
* Validate form data
* Create animations
* Fetch data from APIs
* Build interactive web applications
* Work with browsers through the **DOM**
* Run on servers using **Node.js**
* Build applications with frameworks such as React, Vue, and Angular

### A simple real-world example

Imagine a **shopping cart**.

When you click:

> **Add to Cart**

JavaScript can:

1. Detect the click
2. Identify the product
3. Add it to the cart
4. Update the cart quantity
5. Calculate the total price
6. Update the page without refreshing it

That's where JavaScript becomes powerful.

### 🎯 Interview answer

If an interviewer asks **"What is JavaScript?"**, you can say:

> **"JavaScript is a high-level, dynamically typed programming language mainly used to add interactivity and dynamic behavior to web pages. It runs in browsers and can also run on servers using environments like Node.js."**

That's a much stronger answer than simply saying *"JavaScript makes websites interactive."*
