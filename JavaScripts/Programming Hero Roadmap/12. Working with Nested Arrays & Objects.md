Absolutely. This is the point where JavaScript starts looking much more like **real-world application data**.

You've already learned arrays and objects separately. Now we'll combine them:

> **Arrays can contain objects, objects can contain arrays, and both can contain other arrays/objects.**

# 🧠 Lesson 11: Working with Nested Arrays & Objects

```text

│                    ├── CSS
```

# 1️⃣7️⃣ Optional Chaining `?.`

This is **very important when working with API data**.

Imagine:

```js id="g6t0rm"
const user = {
    name: "Nayeem"
};
```

There is no `address`.

If you do:

```js id="1r3y6t"
console.log(user.address.city);
```

JavaScript throws an error because:

```text id="7z8j4y"
user.address → undefined
```

You can safely access it with:

```js id="5h1y0s"
console.log(user.address?.city);
```

Result:

```text id="3dj4g8"
undefined
```

No error.

### This is called:

> **Optional chaining**

It basically means:

> "If this property exists, continue. Otherwise, give me `undefined` instead of throwing an error."

# 1️⃣9️⃣ Nullish Coalescing `??`

This is extremely useful with incomplete API data.

# ⭐ 2️⃣3️⃣ A Very Important Skill: Read the Structure First

When you receive complicated data, **don't immediately write code**.

First understand the structure.

For example:

```js id="4h6x8k"
const data = {
    users: [
        {
            name: "Nayeem",
            posts: [
                {
                    title: "JavaScript Basics",
                    comments: [
                        {
                            author: "Rahim",
                            text: "Great post!"
                        }
                    ]
                }
            ]
        }
    ]
};
```

To get the comment author's name:

```js id="a6clg5"
data.users[0].posts[0].comments[0].author
```

Break it down:

```text id="n7r9j1"
data
 ↓
users
 ↓
[0]
 ↓
posts
 ↓
[0]
 ↓
comments
 ↓
[0]
 ↓
author
```

Result:

```text id="l8h4bd"
Rahim
```

### 🧠 Mentor technique

Whenever you see nested data, ask:

> **"What type am I at each level?"**

For example:

```text id="yq5jgo"
data       → Object
users      → Array
users[0]   → Object
posts      → Array
posts[0]   → Object
comments   → Array
comments[0]→ Object
author     → String
```

This single habit will make nested data much easier.
