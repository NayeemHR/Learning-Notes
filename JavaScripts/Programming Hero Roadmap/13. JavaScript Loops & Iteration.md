# 🚀 JavaScript Loops & Iteration

## 1. What is a Loop?

A **loop** allows us to execute the same block of code repeatedly.

Imagine you have:

```js
const users = ["Nayeem", "Rahim", "Karim", "Hasan"];
```

Without a loop:

```js
console.log(users[0]);
console.log(users[1]);
console.log(users[2]);
console.log(users[3]);
```

With a loop:

```js
for (let i = 0; i < users.length; i++) {
  console.log(users[i]);
}
```

Output:

```text
Nayeem
Rahim
Karim
Hasan
```

### 🧠 Mental model

Think:

> **Start → Check → Execute → Update → Check again**

---

# 2. `for` Loop

The traditional `for` loop is one of the most important loops to understand.

```js
for (initialization; condition; update) {
  // code
}
```

Example:

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

Output:

```text
0
1
2
3
4
```

Let's break it down:

```js
let i = 0
```

Start `i` at `0`.

```js
i < 5
```

Continue while `i` is less than `5`.

```js
i++
```

Increase `i` by `1` after each iteration.

### Execution

```text
i = 0 → print 0
i = 1 → print 1
i = 2 → print 2
i = 3 → print 3
i = 4 → print 4
i = 5 → stop
```

---

# 3. What is an Iteration?

One execution of the loop body is called an **iteration**.

```js
for (let i = 0; i < 3; i++) {
  console.log("Hello");
}
```

There are **3 iterations**.

```text
Iteration 1 → Hello
Iteration 2 → Hello
Iteration 3 → Hello
```

So:

> **Loop = the mechanism that repeats**
>
> **Iteration = one repetition**

# 4. Loop Through an Array

Suppose:

```js
const fruits = ["Apple", "Banana", "Mango"];
```

Using `for`:

```js
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

Output:

```text
Apple
Banana
Mango
```

### Why `fruits[i]`?

Because `i` represents the index.

```text
i = 0 → fruits[0] → Apple
i = 1 → fruits[1] → Banana
i = 2 → fruits[2] → Mango
```

---

# 5. `for...of` Loop

JavaScript provides a much cleaner way to loop through arrays.

```js
const fruits = ["Apple", "Banana", "Mango"];

for (const fruit of fruits) {
  console.log(fruit);
}
```

Output:

```text
Apple
Banana
Mango
```

Here:

```js
fruit
```

directly represents the current value.

### Compare

Traditional:

```js
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

`for...of`:

```js
for (const fruit of fruits) {
  console.log(fruit);
}
```

### 🧠 Rule

Use:

```js
for...of
```

when you primarily need the **values**.

---

# 6. `for...in` Loop

`for...in` is commonly used to iterate over **object keys**.

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer"
};

for (const key in user) {
  console.log(key);
}
```

Output:

```text
name
age
role
```

But you can get the values too:

```js
for (const key in user) {
  console.log(user[key]);
}
```

Output:

```text
Nayeem
25
Developer
```

Or both:

```js
for (const key in user) {
  console.log(key, user[key]);
}
```

Output:

```text
name Nayeem
age 25
role Developer
```

### 🧠 Important distinction

| Loop       | Common use              |
| ---------- | ----------------------- |
| `for`      | General-purpose looping |
| `for...of` | Array/iterable values   |
| `for...in` | Object keys             |

### ⚠️ Interview point

Don't normally use:

```js
for...in
```

for arrays when you simply want their values.

Prefer:

```js
for...of
```

# 7. `while` Loop

A `while` loop runs **while a condition is true**.

```js
let i = 0;

while (i < 5) {
  console.log(i);
  i++;
}
```

Output:

```text
0
1
2
3
4
```

The important part is:

```js
i++;
```

If you forget it:

```js
let i = 0;

while (i < 5) {
  console.log(i);
}
```

⚠️ This creates an **infinite loop**, because `i` never changes.

---

# 8. `do...while`

A `do...while` loop is slightly different.

It executes the code **at least once**, then checks the condition.

```js
let i = 10;

do {
  console.log(i);
  i++;
} while (i < 5);
```

Output:

```text
10
```

Why?

Because the `do` block executes first.

Then JavaScript checks:

```js
10 < 5
```

which is false.

### Difference

`while`:

```js
while (condition) {
  // code
}
```

May execute **zero times**.

`do...while`:

```js
do {
  // code
} while (condition);
```

Executes **at least once**.

# 9. `break`

`break` completely stops the loop.

```js
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;
  }

  console.log(i);
}
```

Output:

```text
0
1
2
3
4
```

When:

```js
i === 5
```

JavaScript encounters:

```js
break;
```

and exits the loop.

### 🧠 Mental model

> `break` = **Stop the entire loop**

---

# 10. `continue`

`continue` skips the **current iteration** and moves to the next one.

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue;
  }

  console.log(i);
}
```

Output:

```text
0
1
3
4
```

When `i` is `2`, JavaScript skips:

```js
console.log(i);
```

but the loop continues.

### Remember

```text
break     → stop loop completely
continue  → skip current iteration
```

# 11. Nested Loops

A loop inside another loop is called a **nested loop**.

Example:

```js
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 2; j++) {
    console.log(i, j);
  }
}
```

Output:

```text
1 1
1 2
2 1
2 2
3 1
3 2
```

### How does it work?

For every one iteration of the outer loop, the inner loop runs completely.

```text
i = 1
  j = 1
  j = 2

i = 2
  j = 1
  j = 2

i = 3
  j = 1
  j = 2
```

This becomes very useful when working with **nested arrays**.

# 12. Looping Through Nested Arrays

For example:

```js
const groups = [
  ["Apple", "Banana"],
  ["Mango", "Orange"],
  ["Grape", "Watermelon"]
];
```

We can use nested `for...of`:

```js
for (const group of groups) {
  for (const fruit of group) {
    console.log(fruit);
  }
}
```

Output:

```text
Apple
Banana
Mango
Orange
Grape
Watermelon
```

# 13. Looping Through Array of Objects

This is extremely important in real-world JavaScript.

```js
const users = [
  {
    name: "Nayeem",
    age: 25
  },
  {
    name: "Rahim",
    age: 30
  },
  {
    name: "Karim",
    age: 22
  }

```

Using `for...of`:

```js
for (const user of users) {
  console.log(user.name);
}
```

Output:

```text
Nayeem
Rahim
Karim
```

We can also check conditions:

```js
for (const user of users) {
  if (user.age >= 25) {
    console.log(user.name);
  }
}
```

Output:

```text
Nayeem
Rahim
```

Consider:

```js
const users = [
  {
    name: "Nayeem",
    address: {
      city: "Dhaka",
```


```text
users
```

# 15. Loop vs Array Methods

This is very important for modern JavaScript.

You already learned:

```js
map()
filter()
find()
some()
every()
forEach()
```

These are also ways of **iterating over arrays**, but they serve different purposes.

For example:

### `for...of`

```js
for (const user of users) {
  console.log(user.name);
}
```

### `forEach`

```js
users.forEach(user => {
  console.log(user.name);
});
```

### `map`

Use when you want to **create a new array**:

```js
const names = users.map(user => user.name);
```

### `filter`

Use when you want to **select matching items**:

```js
const adults = users.filter(user => user.age >= 18);
```

### `find`

Use when you want **one matching item**:

```js
const user = users.find(user => user.name === "Nayeem");
```

### 🧠 Quick decision guide

```text
Need to repeat general logic?
        ↓
     for/of

Need to perform something for every item?
        ↓
     forEach

Need a new transformed array?
        ↓
      map

Need matching items?
        ↓
     filter

Need first matching item?
        ↓
      find

Need true/false?
        ↓
   some / every
```

# 16. A Very Important Interview Question

### What is the difference between `for...of` and `for...in`?

**Answer:**

> `for...of` iterates over the values of an iterable such as an array, while `for...in` iterates over the enumerable property keys of an object.

Example:

```js
const fruits = ["Apple", "Banana"];

for (const fruit of fruits) {
  console.log(fruit);
}
```

Output:

```text
Apple
Banana
```

But:

```js
for (const index in fruits) {
  console.log(index);
}
```

Output:

```text
0
1
```

So remember:

```text
for...of  → values
for...in  → keys
```
