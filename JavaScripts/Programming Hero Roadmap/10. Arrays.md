# 🧠 Lesson 9: Arrays in JavaScript

## 1. What is an Array?

An **array is a data structure that allows you to store multiple values in a single variable.**

Without an array:

```js
let fruit1 = "Apple";
let fruit2 = "Banana";
let fruit3 = "Mango";
```

With an array:

```js
let fruits = ["Apple", "Banana", "Mango"];
```

Much cleaner.

Think of an array like a row of numbered boxes:

```text
┌─────────┬──────────┬─────────┐
│  Apple  │  Banana  │  Mango  │
└─────────┴──────────┴─────────┘
     0          1         2
```

The numbers are called **indexes**.

---

# 2️⃣ Creating an Array

The most common syntax is:

```js
let fruits = ["Apple", "Banana", "Mango"];
```

You can also create an empty array:

```js
let fruits = [];
```

Then add values later.

```js
fruits[0] = "Apple";
fruits[1] = "Banana";
```

---

# 3️⃣ Array Indexing

JavaScript arrays use **zero-based indexing**.

```js
let fruits = ["Apple", "Banana", "Mango"];
```

Indexes:

```text
Apple  → 0
Banana → 1
Mango  → 2
```

So:

```js
console.log(fruits[0]);
```

Output:

```text
Apple
```

And:

```js
console.log(fruits[2]);
```

Output:

```text
Mango
```

---

# 4️⃣ Getting the Last Element

You can get the last element using:

```js
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits[fruits.length - 1]);
```

Output:

```text
Mango
```

Because:

```text
length = 3
last index = 3 - 1 = 2
```

### Modern JavaScript

You can also use:

```js
console.log(fruits.at(-1));
```

This also gives:

```text
Mango
```

---

# 5️⃣ Arrays Can Store Different Data Types

JavaScript arrays can contain different types:

```js
let data = [
    "Nayeem",
    25,
    true,
    null
];
```

You can even have objects:

```js
let users = [
    { name: "Nayeem", age: 25 },
    { name: "Rahim", age: 30 }
];
```

However, in real applications, arrays usually contain values of a related kind.

For example:

```js
let prices = [100, 200, 300];
```

or:

```js
let names = ["Nayeem", "Rahim", "Karim"];
```

---

# 6️⃣ Array Length

Just like strings, arrays have a `length` property.

```js
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.length);
```

Output:

```text
3
```

Remember:

> `length` tells you how many elements are in the array.

---

# 7️⃣ Changing an Array Element

Unlike strings, arrays are **mutable**.

You can change an element:

```js
let fruits = ["Apple", "Banana", "Mango"];

fruits[1] = "Orange";

console.log(fruits);
```

Output:

```js
["Apple", "Orange", "Mango"]
```

So:

```text
Strings → Immutable
Arrays  → Mutable
```

This is an important distinction.

---

# 8️⃣ Adding Elements with `push()`

`push()` adds an element to the **end** of an array.

```js
let fruits = ["Apple", "Banana"];

fruits.push("Mango");

console.log(fruits);
```

Result:

```js
["Apple", "Banana", "Mango"]
```

You can add multiple values:

```js
fruits.push("Orange", "Grapes");
```

Now:

```js
["Apple", "Banana", "Mango", "Orange", "Grapes"]
```

### Important

`push()` changes the original array.

---

# 9️⃣ Removing Elements with `pop()`

`pop()` removes the **last element**.

```js
let fruits = ["Apple", "Banana", "Mango"];

fruits.pop();

console.log(fruits);
```

Result:

```js
["Apple", "Banana"]
```

Interestingly, `pop()` also **returns the removed value**.

```js
let fruits = ["Apple", "Banana", "Mango"];

let removed = fruits.pop();

console.log(removed);
```

Output:

```text
Mango
```

---

# 🔟 `unshift()`

`unshift()` adds elements to the **beginning**.

```js
let fruits = ["Banana", "Mango"];

fruits.unshift("Apple");

console.log(fruits);
```

Result:

```js
["Apple", "Banana", "Mango"]
```

---

# 1️⃣1️⃣ `shift()`

`shift()` removes the **first element**.

```js
let fruits = ["Apple", "Banana", "Mango"];

fruits.shift();

console.log(fruits);
```

Result:

```js
["Banana", "Mango"]
```

It also returns the removed element:

```js
let removed = fruits.shift();

console.log(removed);
```

---

# 📊 The Four Basic Array Methods

These are essential:

| Method      | Action                |
| ----------- | --------------------- |
| `push()`    | Add to end            |
| `pop()`     | Remove from end       |
| `unshift()` | Add to beginning      |
| `shift()`   | Remove from beginning |

Think:

```text
Beginning                    End
    ↓                         ↓
[ Apple | Banana | Mango ]
    ↑                         ↑
 shift                     pop
 unshift                   push
```

# 1️⃣2️⃣ `includes()`

You can check whether an array contains a value.

```js
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.includes("Banana"));
```

Output:

```text
true
```

And:

```js
console.log(fruits.includes("Orange"));
```

Output:

```text

```

Very useful for checking whether something exists.

# 1️⃣3️⃣ `indexOf()`

Find the index of an element:

```js
let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits.indexOf("Banana"));
```

Output:

```text
1
```

If it doesn't exist:

```js
console.log(fruits.indexOf("Orange"));
```

Output:

```text
-1
```

---

# 1️⃣4️⃣ `join()`

`join()` converts an array into a string.

```js
let fruits = ["Apple", "Banana", "Mango"];

let result = fruits.join(", ");

console.log(result);
```

Output:

```text
Apple, Banana, Mango
```

Remember our string lesson:

```text
split() → String → Array
join()  → Array → String
```

---

# 1️⃣5️⃣ `slice()`

`slice()` creates a **new array** containing part of the original array.

```js
let fruits = ["Apple", "Banana", "Mango", "Orange"];

let result = fruits.slice(1, 3);

console.log(result);
```

Output:

```js
["Banana", "Mango"]
```

Just like string `slice()`:

> The ending index is not included.

### Important

`slice()` does **not** modify the original array.

---

# 1️⃣6️⃣ `splice()`

`splice()` can **add, remove, or replace** elements.

Example:

```js
let fruits = ["Apple", "Banana", "Mango"];

fruits.splice(1, 1);

console.log(fruits);
```

Result:

```js
["Apple", "Mango"]
```

Let's understand:

```js
splice(1, 1)
```

means:

```text
Start at index 1
Remove 1 element
```

---

## Adding with `splice()`

```js
let fruits = ["Apple", "Mango"];

fruits.splice(1, 0, "Banana");

console.log(fruits);
```

Result:

```js
["Apple", "Banana", "Mango"]
```

Here:

```text
1 → starting index
0 → remove 0 elements
"Banana" → insert
```

---

# ⚠️ `slice()` vs `splice()`

This is a common interview question.

### `slice()`

```js
let result = arr.slice(1, 3);
```

* Creates a new array
* Does **not** modify the original array

### `splice()`

```js
arr.splice(1, 2);
```

* Modifies the original array
* Can add/remove/replace elements

Remember:

> **slice → copy a portion**

> **splice → modify the array**

# 1️⃣7️⃣ Checking if Something Is an Array

You learned:

```js
typeof []
```

returns:

```text
"object"
```

So `typeof` isn't enough to identify an array.

Use:

```js
Array.isArray([]);
```

Result:

```text
true
```

Example:

```js
let fruits = ["Apple", "Banana"];

```

Output:

```text
true
```

This is the correct way to check for an array.

# 1️⃣8️⃣ Looping Through Arrays

You can use a traditional `for` loop:

```js
let fruits = ["Apple", "Banana", "Mango"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

Output:

```text
Apple
Banana
Mango
```

Here:

```js
fruits[i]
```

gets the current element.

---

# ⭐ 1️⃣9️⃣ `for...of`

A cleaner way to loop through array values:

```js
let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
    console.log(fruit);
}
```

Output:

```text
Apple
Banana
Mango
```

This is very readable.

Think:

> "For each fruit **of** fruits..."

# 2️⃣0️⃣ `forEach()`

Another extremely important array method:

```js
let fruits = ["Apple", "Banana", "Mango"];

fruits.forEach(function (fruit) {
    console.log(fruit);
});
```

You can use an arrow function:

```js
fruits.forEach((fruit) => {
    console.log(fruit);
});
```

This is common modern JavaScript.

# 🔥 2️⃣1️⃣ `map()`

`map()` is one of the **most important array methods**.

It creates a **new array** by transforming every element.

Example:

```js
let numbers = [1, 2, 3, 4];

let doubled = numbers.map((number) => {
    return number * 2;
});

console.log(doubled);
```

Result:

```js
[2, 4, 6, 8]
```

Think:

```text
1 → 2
2 → 4
3 → 6
4 → 8
```

The original remains:

```js
[1, 2, 3, 4]
```

---

# 2️⃣2️⃣ `filter()`

`filter()` creates a new array containing only elements that satisfy a condition.

```js
let numbers = [10, 15, 20, 25, 30];

let result = numbers.filter((number) => {
    return number >= 20;
});

console.log(result);
```

Output:

```js
[20, 25, 30]
```

Think:

```text
10 ❌
15 ❌
20 ✅
25 ✅
30 ✅
```

---

# 2️⃣3️⃣ `find()`

`find()` returns the **first element** that matches a condition.

```js
let numbers = [10, 20, 30, 40];

let result = numbers.find((number) => {
    return number > 20;
});

console.log(result);
```

Output:

```text
30
```

Notice:

`find()` returns **one element**, while `filter()` returns an **array**.

---

# ⭐ `find()` vs `filter()`

```js
let numbers = [10, 20, 30, 40];
```

### `find()`

```js
numbers.find(number => number > 20);
```

Result:

```text
30
```

### `filter()`

```js
numbers.filter(number => number > 20);
```

Result:

```js
[30, 40]
```

Remember:

> **find → first matching element**

> **filter → all matching elements**

---

# 2️⃣4️⃣ `some()`

`some()` checks whether **at least one** element satisfies a condition.

```js
let numbers = [10, 20, 35, 40];

let result = numbers.some((number) => {
    return number > 30;
});

console.log(result);
```

Output:

```text
true
```

Because `35` and `40` are greater than 30.

---

# 2️⃣5️⃣ `every()`

`every()` checks whether **all** elements satisfy a condition.

```js
let numbers = [10, 20, 30];

let result = numbers.every((number) => {
    return number > 5;
});

console.log(result);
```

Output:

```text
true
```

Because every number is greater than 5.

But:

```js
let numbers = [10, 20, 3];

console.log(numbers.every(number => number > 5));
```

returns:

```text
false
```

# 🔥 2️⃣6️⃣ Array Operators

When people say **"array operators"**, they're usually talking about operations you can perform with arrays rather than special array-specific operators.

### Access operator

```js
fruits[0]
```

Gets an element.

### Assignment

```js
fruits[0] = "Orange";
```

Changes an element.

### Spread operator `...`

This is very important in modern JavaScript.

```js
let fruits = ["Apple", "Banana"];

let newFruits = [...fruits, "Mango"];

console.log(newFruits);
```

Result:

```js
["Apple", "Banana", "Mango"]
```

The `...` is called the **spread operator**.

It expands the elements of an array.

---

# 2️⃣7️⃣ Combining Arrays With Spread

```js
let fruits = ["Apple", "Banana"];
let vegetables = ["Carrot", "Potato"];

let food = [...fruits, ...vegetables];

console.log(food);
```

Result:

```js
["Apple", "Banana", "Carrot", "Potato"]
```

This is very common in modern JavaScript and React.

---

# 2️⃣8️⃣ Copying an Array

Be careful with this:

```js
let fruits = ["Apple", "Banana"];

let newFruits = fruits;
```

This does **not create an independent copy**.

Both variables refer to the same array.

```js
newFruits.push("Mango");

console.log(fruits);
```

You might be surprised:

```js
["Apple", "Banana", "Mango"]
```

Instead, use:

```js
let newFruits = [...fruits];
```

Now you have a shallow copy.
