# 🧠 Lesson 3: Operators & Expressions in JavaScript

First, understand the difference:

### Operator

An **operator** is a symbol or keyword that performs an operation on values.

Examples:

```js
+
-
*
/
>
===
&&
```

### Expression

An **expression** is a piece of code that produces a value.

For example:

```js
10 + 5
```

This is an expression because it produces:

```text
15
```

Another example:

```js
age > 18
```

produces either:

```text
true
```

or:

```text
false
```

So remember:

> **Operator = performs an operation**
> **Expression = produces a value**

# 1️⃣ Arithmetic Operators

These are used for mathematical calculations.

| Operator | Meaning        | Example  | Result |
| -------- | -------------- | -------- | ------ |
| `+`      | Addition       | `10 + 5` | `15`   |
| `-`      | Subtraction    | `10 - 5` | `5`    |
| `*`      | Multiplication | `10 * 5` | `50`   |
| `/`      | Division       | `10 / 5` | `2`    |
| `%`      | Remainder      | `10 % 3` | `1`    |
| `**`     | Exponentiation | `2 ** 3` | `8`    |

### Example

```js
let a = 10;
let b = 3;

console.log(a + b); // 13
console.log(a - b); // 7
console.log(a * b); // 30
console.log(a / b); // 3.333...
console.log(a % b); // 1
console.log(a ** b); // 1000
```

### ⭐ `%` is important

The `%` operator gives you the **remainder**.

```js
10 % 3
```

3 goes into 10 three times, with **1 left over**.

So:

```text
10 % 3 = 1
```

This is commonly used to check whether a number is even or odd:

```js
let number = 10;

console.log(number % 2);
```

Result:

```text
0
```

Therefore, `10` is even.

# 2️⃣ Assignment Operators

Assignment operators are used to **assign or update values**.

The basic assignment operator is:

```js
=
```


Here `=` assigns `100` to `score`.

You can also write:

```js
let score = 100;
```

This means:

```js
score = score + 20;
```

Result:

```text
120
```

Similarly:

```js
score -= 10;
```

means:

```js
score = score - 10;
```

And:

```js
score *= 2;
```

means:

```js
score = score * 2;
```

And:

```js
score /= 2;
```

means:

```js
score = score / 2;
```

### Common assignment operators

```text
= 
+=
-=
*=
/=
%=
**=
```

# ⭐ 4️⃣ `==` vs `===`

This is **very important** in JavaScript interviews.

Consider:

```js
let a = 5;
let b = "5";

console.log(a == b);
```

Result:

```text
true
```

Why?

Because `==` performs **type coercion** before comparing.

But:

```js
console.log(a === b);
```

Result:

```text
false
```

Because `===` checks both:

1. Value
2. Data type

Here:

```text
5   → number
"5" → string
```

So they aren't strictly equal.

### Mentor rule ⭐

In modern JavaScript:

> **Prefer `===` and `!==` over `==` and `!=` unless you have a specific reason to use loose equality.**

# 5️⃣ Logical Operators

Logical operators are used to combine or manipulate conditions.

There are three main ones:

```text
&&
||
!
```

---

## `&&` — AND

Both conditions must be true.

```js
let age = 25;
let hasID = true;

console.log(age >= 18 && hasID);
```

Result:

```text
true
```

Think:

> **Condition A AND Condition B must both be true.**

Example:

```js
age >= 18 && hasID
```

Means:

> "Is the person 18 or older AND do they have an ID?"

---

# `||` — OR

At least one condition must be true.

```js
let hasCash = false;
let hasCard = true;

console.log(hasCash || hasCard);
```

Result:

```text
true
```

Because the second condition is true.

Think:

> **This OR that.**

---

# `!` — NOT

`!` reverses a Boolean value.

```js
let isLoggedIn = true;

console.log(!isLoggedIn);
```

Result:

```text
false
```

Because:

```text
!true → false
!false → true
```

# 6️⃣ Increment and Decrement

These are commonly used with loops.

### Increment

```js
let count = 5;

count++;
```

Now:

```text
count = 6
```

It's essentially:

```js
count = count + 1;
```

### Decrement

```js
let count = 5;

count--;
```

Now:

```text
count = 4
```

It's essentially:

```js
count = count - 1;
```

---

# ⭐ 7️⃣ Prefix vs Postfix

This is slightly more advanced but very important.

Consider:

```js
let x = 5;

console.log(x++);
```

Output:

```text
5
```

But afterward:

```text
x = 6
```

Because `x++` returns the **old value first**, then increments.

Now:

```js
let x = 5;

console.log(++x);
```

Output:

```text
6
```

Because `++x` increments **first**, then returns the new value.

Remember:

```text
x++ → use first, increment afterward
++x → increment first, use afterward
```

The `+` operator can also join strings.

```js
let firstName = "Nayeem";

let fullName = firstName + " " + lastName;

console.log(fullName);
```

Output:

```text
Nayeem Hassan
```

So `+` can mean either:

**Mathematical addition**

```js
10 + 5
```

or:

**String concatenation**

```js
"Hello " + "World"
```

# ⚠️ A Very Important JavaScript Behavior

Look at this:

```js
console.log(5 + 5);
```

Result:

```text
10
```

But:

```js
console.log("5" + 5);
```

Result:

```text
"55"
```

Why?

Because when `+` involves a string, JavaScript can convert the other value to a string and concatenate them.

This is called **type coercion**.

We'll study type coercion more deeply later.

# 9️⃣ Ternary Operator

The ternary operator is a short way of writing a simple condition.

Syntax:

```js
condition ? valueIfTrue : valueIfFalse
```

Example:

```js
let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);
```

Output:

```text
Adult
```

This is basically a short version of:

```js
if (age >= 18) {
    result = "Adult";
} else {
    result = "Minor";
}
```

Ternary operators are very common in modern JavaScript and React.

# 🔟 Operator Precedence

JavaScript doesn't simply calculate everything from left to right.

For example:

```js
let result = 10 + 5 * 2;
```

You might think:

```text
10 + 5 = 15
15 * 2 = 30
```

But JavaScript gives multiplication higher precedence.

So:

```text
5 * 2 = 10
10 + 10 = 20
```

Result:

```text
20
```

You can use parentheses to control the order:

```js
let result = (10 + 5) * 2;
```

Now:

```text
15 * 2 = 30
```

### Mentor rule

When an expression becomes complicated:

> **Use parentheses to make your intention clear.**

# 🧠 Let's Put Everything Together

Consider this:

```js
let price = 1000;
let discount = 200;

let finalPrice = price - discount;

console.log(finalPrice);
```

Here:

```text
price - discount
```

is an **expression**.

`-` is an **operator**.

`price` and `discount` are **operands**.

Result:

```text
800
```

So you can think of it as:

```text
Operand    Operator    Operand
  1000        -          200
              ↓
             800
```
