Absolutely. You now know **variables, data types, operators, expressions, and strings**, so you're ready for one of the most important JavaScript concepts:

# 🧠 Lesson 5: Conditions in JavaScript

Conditions allow your program to **make decisions**.

Think about real life:

> If it is raining → take an umbrella.
> Otherwise → don't take an umbrella.

JavaScript can make the same kind of decisions.

```js
if (isRaining) {
    console.log("Take an umbrella");
}
```

---

# 1️⃣ The `if` Statement

The basic syntax is:

```js
if (condition) {
    // code runs if condition is true
}
```

Example:

```js
let age = 20;

if (age >= 18) {
    console.log("You are an adult");
}
```

Since:

```text
20 >= 18
```

is `true`, JavaScript executes the code inside `{}`.

Output:

```text
You are an adult
```

---

# 2️⃣ How Does `if` Work?

Let's break this down:

```js
if (age >= 18) {
    console.log("Adult");
}
```

### Step 1

JavaScript evaluates:

```js
age >= 18
```

### Step 2

It gets:

```text
true
```

### Step 3

Because the condition is `true`, JavaScript executes:

```js
console.log("Adult");
```

So the basic idea is:

```text
Condition
    ↓
 true? ──→ YES → Run the code
    ↓
   NO
    ↓
Skip the code
```

---

# 3️⃣ `if...else`

What if you want something to happen when the condition is false?

Use `else`.

```js
let age = 16;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
```

Since `16 >= 18` is false:

```text
Minor
```

### Think of it as:

```text
IF condition is true
    → do this

ELSE
    → do that
```

---

# 4️⃣ `else if`

Sometimes you have **multiple conditions**.

For example, grading:

```js
let marks = 75;

if (marks >= 80) {
    console.log("A+");
} else if (marks >= 70) {
    console.log("A");
} else if (marks >= 60) {
    console.log("A-");
} else {
    console.log("Below A-");
}
```

Here JavaScript checks from **top to bottom**.

For `75`:

```text
75 >= 80 ❌
75 >= 70 ✅
```

So it prints:

```text
A
```

Once JavaScript finds a true condition, it executes that block and skips the remaining `else if` conditions.

---

# ⭐ 5️⃣ Order Matters

Look carefully at this:

```js
let marks = 85;

if (marks >= 60) {
    console.log("Pass");
} else if (marks >= 80) {
    console.log("A+");
}
```

Output:

```text
Pass
```

Why?

Because:

```js
marks >= 60
```

is already true.

JavaScript never reaches:

```js
marks >= 80
```

So generally, put **more specific/highest-priority conditions first**.

Better:

```js
if (marks >= 80) {
    console.log("A+");
} else if (marks >= 60) {
    console.log("Pass");
}
```

---

# 6️⃣ Conditions With Comparison Operators

You can use all the comparison operators you learned earlier.

```js
let age = 25;

age > 18
age < 30
age >= 18
age <= 25
age === 25
age !== 20
```

For example:

```js
if (age === 25) {
    console.log("Age is 25");
}
```

### ⭐ Prefer `===`

As we discussed earlier:

```js
5 == "5"   // true
5 === "5"  // false
```

So use:

```js
if (age === 25)
```

rather than:

```js
if (age == 25)
```

in most modern JavaScript code.

---

# 7️⃣ Conditions With `&&`

You can combine multiple conditions using **AND**.

```js
let age = 25;
let hasID = true;

if (age >= 18 && hasID === true) {
    console.log("You can enter");
}
```

Both must be true:

```text
age >= 18     → true
hasID === true → true

true && true → true
```

Therefore:

```text
You can enter
```

---

# 8️⃣ Conditions With `||`

`||` means **OR**.

```js
let day = "Friday";

if (day === "Friday" || day === "Saturday") {
    console.log("Weekend");
}
```

Only one condition needs to be true.

```text
Friday === Friday → true
Saturday === Friday → false

true || false → true
```

So:

```text
Weekend
```

---

# 9️⃣ Conditions With `!`

`!` means **NOT**.

```js
let isLoggedIn = false;

if (!isLoggedIn) {
    console.log("Please log in");
}
```

Since:

```text
!false → true
```

the message is printed.

A common real-world pattern:

```js
if (!user) {
    console.log("User not found");
}
```

---

# 🔥 10️⃣ Truthy and Falsy Values

This is a **very important JavaScript concept**.

You don't always need to write:

```js
if (isLoggedIn === true)
```

You can simply write:

```js
if (isLoggedIn)
```

JavaScript automatically evaluates a value as either **truthy** or **falsy**.

### Falsy values

You should memorize these:

```text
false
0
-0
0n
""
null
undefined
NaN
```

These behave like `false` in a condition.

Example:

```js
let username = "";

if (username) {
    console.log("Username exists");
}
```

Since an empty string is falsy, nothing is printed.

But:

```js
let username = "Nayeem";

if (username) {
    console.log("Username exists");
}
```

prints:

```text
Username exists
```

Because a non-empty string is truthy.

---

# ⭐ 11️⃣ Truthy Values

Almost everything else is truthy.

For example:

```js
if ("Hello") {
    console.log("True");
}
```

```js
if (100) {
    console.log("True");
}
```

```js
if ([]) {
    console.log("True");
}
```

```js
if ({}) {
    console.log("True");
}
```

These are all truthy.

### ⚠️ Important

An empty array:

```js
[]
```

is truthy.

An empty object:

```js
{}
```

is also truthy.

This surprises many beginners.

---

# 1️⃣2️⃣ Nested Conditions

You can put an `if` inside another `if`.

```js
let age = 25;
let hasID = true;

if (age >= 18) {
    if (hasID) {
        console.log("Entry allowed");
    }
}
```

This is called a **nested condition**.

However, don't overuse nested conditions. Sometimes logical operators make the code cleaner:

```js
if (age >= 18 && hasID) {
    console.log("Entry allowed");
}
```

---

# 1️⃣3️⃣ Ternary Operator

You already learned this in operators.

A ternary operator is useful for **simple conditions**.

```js
let age = 20;

let status = age >= 18 ? "Adult" : "Minor";

console.log(status);
```

Output:

```text
Adult
```

Think:

```text
condition ? ifTrue : ifFalse
```

Use `if/else` when the logic becomes complicated.

let total = 1500;

    console.log("20% discount");

    console.log("10% discount");

1500 >= 2000 → false

# 1️⃣6️⃣ `switch` Statement

There is another way to handle multiple conditions: `switch`.

For example:

```js
let day = "Monday";

switch (day) {
    case "Monday":
        console.log("Start of the week");
        break;

    case "Friday":
        console.log("Almost weekend");
        break;

    case "Saturday":
        console.log("Weekend");
        break;

    default:
        console.log("Normal day");
}
```

Output:

```text
Start of the week
```

### Why `break`?

Without `break`, JavaScript can continue executing the following cases.

For now, think:

> `switch` is useful when you're comparing **one value against multiple specific values**.

---

# 🧠 `if` vs `switch`

Use `if` when you have conditions such as:

```js
age >= 18
price > 1000
score < 50
```

Use `switch` when you're checking one value against specific options:

```js
day === "Monday"
day === "Friday"
day === "Sunday"
```
