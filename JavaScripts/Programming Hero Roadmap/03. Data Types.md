# 🧠 Lesson 2: Data Types in JavaScript

First, understand this simple idea:

> **A data type tells JavaScript what kind of value a variable contains.**

For example:

```js
let name = "Nayeem";
let age = 25;
let isDeveloper = true;
```

Here:

* `"Nayeem"` → **String**
* `25` → **Number**
* `true` → **Boolean**

JavaScript has **8 main data types**.

### Primitive Types — 7

1. String
2. Number
3. BigInt
4. Boolean
5. Undefined
6. Null
7. Symbol

### Non-Primitive Type — 1

8. Object

Let's understand them one by one.

---

# 1️⃣ String

A **string** represents text.

You can use:

```js
let name = "Nayeem";
```

or:

```js
let name = 'Nayeem';
```

You can also use backticks:

```js
let name = `Nayeem`;
```

### Example

```js
let message = "Hello World";
let country = "Bangladesh";
```

Both are strings.

You can check the type using `typeof`:

```js
console.log(typeof message);
```

Output:

```text
string
```

### Important

A number inside quotes becomes a **string**:

```js
let age = "25";
```

This is **not** a number.

```js
typeof age
```

returns:

```text
string
```

Compare:

```js
let age1 = 25;
let age2 = "25";
```

`age1` → Number
`age2` → String

This distinction becomes **very important** when working with forms and APIs.

---

# 2️⃣ Number

JavaScript uses `Number` for both integers and decimal numbers.

```js
let age = 25;
let price = 99.99;
let temperature = -5;
```

All three are numbers.

```js
console.log(typeof price);
```

Output:

```text
number
```

Unlike some programming languages, JavaScript doesn't have separate basic types for:

```text
int
float
double
```

They are all generally represented by `Number`.

---

# 3️⃣ Boolean

A Boolean has only **two possible values**:

```js
true
false
```

Example:

```js
let isLoggedIn = true;
let isAdmin = false;
```

You commonly use Booleans with conditions:

```js
if (isLoggedIn) {
    console.log("Welcome!");
}
```

Boolean is extremely important for programming logic.

Think:

> **Boolean = Yes/No, True/False, On/Off**

---

# 4️⃣ Undefined

`undefined` means a variable has been declared but hasn't been given a value.

```js
let username;

console.log(username);
```

Output:

```text
undefined
```

And:

```js
console.log(typeof username);
```

Output:

```text
undefined
```

So:

```js
let username;
```

means:

> "The variable exists, but I haven't assigned a value yet."

---

# 5️⃣ Null

`null` represents an **intentional absence of a value**.

For example:

```js
let selectedUser = null;
```

This can mean:

> "There is currently no selected user."

### `undefined` vs `null`

This is an important interview question.

**Undefined:**

```js
let user;
```

You haven't assigned anything.

**Null:**

```js
let user = null;
```

You intentionally assigned "no value."

So remember:

> **undefined → value hasn't been assigned**
> **null → intentionally no value**

### Interesting JavaScript behavior

```js
typeof null
```

returns:

```text
object
```

😅 This is a famous JavaScript historical quirk.

`null` is **not actually an object**, despite `typeof null` returning `"object"`.

---

# 6️⃣ BigInt

`BigInt` is used for **very large integers** that are beyond the safe integer range of JavaScript's `Number`.

Example:

```js
let bigNumber = 123456789012345678901234567890n;
```

Notice the `n` at the end.

```js
typeof bigNumber
```

returns:

```text
bigint
```

You won't use BigInt every day, but you should know it exists.

---

# 7️⃣ Symbol

`Symbol` creates a unique value.

Example:

```js
let id = Symbol("id");
```

Even if two Symbols have the same description:

```js
let id1 = Symbol("id");
let id2 = Symbol("id");
```

They are different:

```js
console.log(id1 === id2);
```

Output:

```text
false
```

Symbols are mainly useful when you need **unique identifiers**, especially in advanced JavaScript.

Don't worry too much about this one yet.

---

# 8️⃣ Object

Objects allow us to store **multiple related values together**.

Example:

```js
let user = {
    name: "Nayeem",
    age: 25,
    country: "Bangladesh"
};
```

Here `user` is an object.

You can access its properties:

```js
console.log(user.name);
```

Output:

```text
Nayeem
```

And:

```js
console.log(user.age);
```

Output:

```text
25
```

Objects are extremely important in JavaScript. We'll spend a lot more time on them later.

---

# 🧩 What about Arrays?

You'll often hear:

```js
let skills = ["HTML", "CSS", "JavaScript"];
```

This is an **Array**.

Technically, an array is a specialized type of **object** in JavaScript.

```js
typeof skills
```

returns:

```text
object
```

We'll study arrays separately because they're extremely important.

---

# 🔍 The `typeof` Operator

`typeof` allows you to determine the type of a value.

```js
typeof "Hello"
```

→ `"string"`

```js
typeof 25
```

→ `"number"`

```js
typeof true
```

→ `"boolean"`

```js
typeof undefined
```

→ `"undefined"`

```js
typeof 123n
```

→ `"bigint"`

```js
typeof Symbol("id")
```

→ `"symbol"`

And the famous one:

```js
typeof null
```

→ `"object"`

# ⭐ Primitive vs Non-Primitive

This is an important concept.

### Primitive

JavaScript has 7 primitive data types:

```text
String
Number
Boolean
Undefined
Null
BigInt
Symbol
```

Primitive values are **not objects** and represent single values.

### Non-Primitive

```text
Object
```

Objects can contain multiple values and more complex structures.

For example:

```js
let user = {
    name: "Nayeem",
    age: 25
};
```
