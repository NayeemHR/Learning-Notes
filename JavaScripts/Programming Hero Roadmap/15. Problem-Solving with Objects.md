Absolutely. Now let's move from **array problem-solving** to **object problem-solving**.

The goal is not to memorize `Object.keys()`, `Object.values()`, etc. The real skill is learning to look at an object, understand its structure, and decide **what logic the problem requires**.

# 🧠 Problem-Solving with Objects in JavaScript

## 1. First Understand the Object

Suppose we have:

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer",
  country: "Bangladesh"
};
```

Before solving any problem, ask:

> **What type of data am I working with?**

Here:

```text
user → object
name → string
age → number
role → string
country → string
```

That tells us how we can work with it.

---

# 2. The Most Important Object Tools

You should become comfortable with these:

```js
Object.keys()
Object.values()
Object.entries()
```

Let's understand them properly.

### `Object.keys()`

Returns an array containing the object's keys.

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer"
};

console.log(Object.keys(user));
```

Result:

```js
["name", "age", "role"]
```

Think:

```text
Object
   ↓
keys
   ↓
Array of keys
```

---

### `Object.values()`

Returns the values:

```js
console.log(Object.values(user));
```

Result:

```js
["Nayeem", 25, "Developer"]
```

---

### `Object.entries()`

Returns key-value pairs:

```js
console.log(Object.entries(user));
```

Result:

```js
[
  ["name", "Nayeem"],
  ["age", 25],
  ["role", "Developer"]
]
```

This is very useful for iteration.

# 3. Problem #1 — Find a Property

Given:

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer"
};
```

Problem:

> Get the user's name.

Easy:

```js
console.log(user.name);
```

Or:

```js
console.log(user["name"]);
```

Result:

```text
Nayeem
```

### 🧠 Rule

If the property name is known:

```js
user.name
```

If the property name is stored in a variable:

```js
const key = "name";

console.log(user[key]);
```

This is called **dynamic property access**.

# 4. Problem #2 — Check Whether a Property Exists

Given:

```js
const user = {
  name: "Nayeem",
  age: 25
};
```

Does the object have a `name` property?

You can use:

```js
console.log("name" in user);
```

Result:

```text
true
```

Another option:

```js
Object.hasOwn(user, "name");
```

This specifically checks whether `name` is an **own property** of the object.

### 🧠 Interview tip

Modern JavaScript:

```js
Object.hasOwn(user, "name")
```

is a good choice when you specifically mean:

> "Does this object itself contain this property?"

# 7. Problem #5 — Loop Through an Object

This is one of the most important object problems.

Given:

```js
const user = {
  name: "Nayeem",
  age: 25,
  role: "Developer"
};
```

We want:

```text
name → Nayeem
age → 25
role → Developer
```

Use `Object.entries()`:

```js
for (const [key, value] of Object.entries(user)) {
  console.log(key, "→", value);
}
```

Output:

```text
name → Nayeem
age → 25
role → Developer
```

### 🧠 Mental model

`Object.entries()` gives:

```js
[
  ["name", "Nayeem"],
  ["age", 25],
  ["role", "Developer"]
]
```

Then:

```js
const [key, value]
```

destructures each pair.

# 8. Problem #6 — Find the Largest Value in an Object

This is where actual problem-solving begins.

Given:

```js
const scores = {
  Nayeem: 85,
  Rahim: 92,
  Karim: 78,
  Hasan: 95
};
```

Find the highest score.

Expected:

```text
95
```

### Step 1: What do we have?

An object.

### Step 2: What do we need?

The highest **value**.

### Step 3: Get the values

```js
Object.values(scores);
```

Gives:

```js
[85, 92, 78, 95]
```

Now it's an array problem!

We could use:

```js
const highest = Math.max(...Object.values(scores));

console.log(highest);
```

Result:

```text
95
```

### 🧠 Important insight

Many object problems become easier when you convert:

```text
Object
   ↓
Object.values()
   ↓
Array
   ↓
Array methods
```

# 9. Problem #7 — Find the Person With the Highest Score

Now the problem becomes slightly harder.

```js
const scores = {
  Nayeem: 85,
  Rahim: 92,
  Karim: 78,
  Hasan: 95
};
```

We don't just want:

```text
95
```

We want:

```text
Hasan
95
```

We can use `Object.entries()`.

```js
let highestName = "";
let highestScore = -Infinity;

for (const [name, score] of Object.entries(scores)) {
  if (score > highestScore) {
    highestScore = score;
    highestName = name;
  }
}

console.log(highestName);
console.log(highestScore);
```

Output:

```text
Hasan
95
```

### 🧠 This is the same pattern you learned with arrays.

We maintain:

```js
highestScore
```

as the **best answer found so far**.

This is an extremely important problem-solving pattern.

# 11. Problem #9 — Transform an Object

Suppose:

```js
const prices = {
  laptop: 80000,
  mouse: 1500,
  keyboard: 3000
};
```

We want to increase every price by 10%.

This is an interesting problem because `map()` works directly on arrays, not normal objects.

So first:

```js
Object.entries(prices)
```

gives:

```js
[
  ["laptop", 80000],
  ["mouse", 1500],
  ["keyboard", 3000]
]
```

Then we can transform the entries:

```js
const updatedPrices = Object.fromEntries(
  Object.entries(prices).map(([product, price]) => {
    return [product, price * 1.10];
  })
);
```

Result:

```js
{
  laptop: 88000,
  mouse: 1650,
  keyboard: 3300
}
```

### 🧠 Important pattern

```text
Object
  ↓
Object.entries()
  ↓
Array
  ↓
map()
  ↓
Object.fromEntries()
  ↓
Object
```

This pattern is worth remembering.

# 12. Problem #10 — Filter an Object

Suppose:

```js
const products = {
  laptop: 80000,
  mouse: 1500,
  keyboard: 3000,
  monitor: 25000
};
```

We want products costing more than `5000`.

We can do:

```js
const expensiveProducts = Object.fromEntries(
  Object.entries(products).filter(([name, price]) => price > 5000)
);
```

Result:

```js
{
  laptop: 80000,
  monitor: 25000
}
```

Again:

```text
Object
  ↓
entries()
  ↓
filter()
  ↓
fromEntries()
  ↓
Object
```

# 15. Problem #13 — Array of Objects

This is probably one of the most important structures you'll encounter in real projects and APIs.

```js
const users = [
  {
    name: "Nayeem",
    age: 25
  },
  {
    name: "Rahim",
    age: 17
  },
  {
    name: "Karim",
    age: 30
  }
];
```

Find users over 18:

```js
const adults = users.filter(user => user.age >= 18);
```

Get their names:

```js
const names = adults.map(user => user.name);
```

Or chain them:

```js
const adultNames = users
  .filter(user => user.age >= 18)
  .map(user => user.name);
```

Result:

```js
["Nayeem", "Karim"]
```

const jsUsers = users.filter(user =>

# 17. The Most Important Mental Model

When you encounter a complex object, **don't try to understand everything at once.**

Walk through it one level at a time.

For:

```js
const company = {
  name: "Tech Corp",
  employees: [
    {
      name: "Nayeem",
      skills: ["JavaScript", "WordPress"]
    }
  ]
};
```

If you need `"JavaScript"`:

```text
company
   ↓
employees
   ↓
[0]
   ↓
skills
   ↓
[0]
```

Therefore:

```js
company.employees[0].skills[0]
```

Result:

```text
JavaScript
```

### 🧠 Golden rule

> **At every level, identify whether you're dealing with an Object or an Array.**

If it's an object:

```js
object.property
```

If it's an array:

```js
array[index]
```

This single habit will make nested data much easier.

# 18. Your Object Problem-Solving Cheat Sheet

```text
Get property
→ object.name

Dynamic property
→ object[key]

Get keys
→ Object.keys(object)

Get values
→ Object.values(object)

Get key + value
→ Object.entries(object)

Check own property
→ Object.hasOwn(object, key)

Loop through object
→ Object.entries()

Count properties
→ Object.keys(object).length

Convert object → array
→ Object.entries()
→ Object.keys()
→ Object.values()

Convert entries → object
→ Object.fromEntries()

Find highest/lowest value
→ accumulator pattern

Filter object
→ entries() + filter() + fromEntries()

Transform object
→ entries() + map() + fromEntries()
```
