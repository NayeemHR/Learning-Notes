React.js ব্যবহার করা হয় মূলত **interactive, dynamic, এবং maintainable user interface** বানানোর জন্য—বিশেষ করে যখন একটি website শুধু static page না হয়ে application-এর মতো আচরণ করে।

ধরুন আপনি JavaScript দিয়ে একটি simple counter বানালেন:

```js
let count = 0;

button.addEventListener("click", function () {
  count++;
  document.querySelector(".count").textContent = count;
});
```

ছোট project-এ এটা ঠিক আছে। কিন্তু application বড় হলে আপনাকে manually DOM update করতে হবে, কোন element কখন change হবে সেটা track করতে হবে, এবং code দ্রুত messy হয়ে যেতে পারে।

React এই সমস্যা অনেকটা সহজ করে।

## 1. React UI-কে Component এ ভাগ করে

ধরুন একটি website আছে:

```text
Website
├── Header
├── Hero
├── ProductList
│   ├── ProductCard
│   ├── ProductCard
│   └── ProductCard
├── Testimonials
└── Footer
```

React-এ আপনি এগুলোকে আলাদা component করতে পারেন:

```jsx
function Header() {
  return <header>My Website</header>;
}
```

```jsx
function ProductCard() {
  return (
    <div>
      <h2>iPhone</h2>
      <p>$999</p>
    </div>
  );
}
```

তারপর:

```jsx
function App() {
  return (
    <>
      <Header />
      <ProductCard />
      <Footer />
    </>
  );
}
```

এটার সবচেয়ে বড় সুবিধা হলো **reusability**।

একবার `ProductCard` বানিয়ে 100 product-এর জন্য ব্যবহার করতে পারবেন।

## 2. React UI automatically update করে

React শেখার সবচেয়ে গুরুত্বপূর্ণ concept এটা।

ধরুন:

```jsx
const [count, setCount] = useState(0);
```

তারপর:

```jsx
<button onClick={() => setCount(count + 1)}>
  Add
</button>

<p>{count}</p>
```

Button click করলে React নিজেই বুঝবে:

```text
State changed
     ↓
React component re-renders
     ↓
UI updated
```

আপনাকে manually এটা করতে হচ্ছে না:

```js
document.querySelector(...)
```

এটাই React-এর বড় সুবিধাগুলোর একটি।

# 4. React declarative

এটা React বোঝার জন্য খুব গুরুত্বপূর্ণ।

Vanilla JavaScript-এ আপনি সাধারণত browser-কে বলেন:

> এই element খুঁজো → text পরিবর্তন করো → class add করো → button disable করো।

এটা হলো imperative style।

Example:

```js
const button = document.querySelector("#button");
button.disabled = true;
button.textContent = "Loading...";
```

React-এ আপনি বলেন:

```jsx
<button disabled={isLoading}>
  {isLoading ? "Loading..." : "Submit"}
</button>
```

অর্থাৎ:

> `isLoading` যদি true হয় তাহলে UI এমন হবে।

আপনি UI-এর **desired state** describe করেন। React DOM update handle করে।

এটাই declarative programming।

# 5. React দিয়ে reusable component তৈরি করা যায়

ধরুন আপনার website-এ একই button 30 জায়গায় আছে।

Vanilla HTML:

```html
<button class="primary-button">Contact Us</button>
```

React:

```jsx
function Button({ children }) {
  return (
    <button className="primary-button">
      {children}
    </button>
  );
}
```

তারপর:

```jsx
<Button>Contact Us</Button>
<Button>Buy Now</Button>
<Button>Learn More</Button>
```

এক জায়গায় design change করলেই সব button update।

Large application-এ এটা বিশাল সুবিধা।

# 6. Props দিয়ে dynamic component বানানো যায়

```jsx

  return (
    <div>
      <h2>{props.name}</h2>

  );

```

তারপর:

```jsx
<UserCard

<UserCard
  name="John"
  job="Designer"
/>
```

একই component, different data।

এটাকে বলা হয় **props**।

আপনি React-এ প্রায় সবসময় এই pattern ব্যবহার করবেন:

```text
Data
 ↓
Props
 ↓
Component
 ↓
UI
```

```jsx
const products = [
```

```jsx
products.map(product => (
```

## Vanilla JS vs React

| বিষয়                | Vanilla JS         | React             |
| ------------------- | ------------------ | ----------------- |
| Small website       | Excellent          | Often unnecessary |
| Large UI            | Harder to manage   | Easier            |
| Reusable components | Manual             | Built-in concept  |
| State management    | Manual             | Structured        |
| DOM updates         | Manual             | React handles it  |
| Large application   | Can become complex | Designed for it   |
| Next.js foundation  | No                 | Yes               |

## React-এর core idea এক লাইনে

React মূলত এই idea:

```text
UI = function(state)
```

যেমন:

```jsx
function App() {
  const [loggedIn, setLoggedIn] = useState(false);

  return (
    <div>
      {loggedIn ? "Welcome!" : "Please Login"}
    </div>
  );
}
```

State:

```text
loggedIn = false
```

UI:

```text
Please Login
```

State:

```text
loggedIn = true
```

UI:

```text
Welcome!
```

React automatically এই relationship maintain করে।

## আপনার জন্য React শেখার সঠিক order

আপনি যেহেতু JavaScript শেখা শুরু করেছেন, React-এ যাওয়ার আগে অন্তত এগুলো comfortable হওয়া উচিত:

```text
1. Variables
2. Data Types
3. Conditionals
4. Functions
5. Arrays
6. Objects
7. Loops
8. Array methods
   - map()
   - filter()
   - find()
9. Destructuring
10. Spread operator
11. Arrow functions
12. DOM basics
13. Events
14. Promises
15. async / await
16. fetch()
17. ES Modules
```

এরপর React:

```text
React
│
├── JSX
├── Components
├── Props
├── Events
├── State
├── Conditional Rendering
├── Lists
├── Forms
├── useState
├── useEffect
├── API fetching
├── Custom Hooks
└── Context
```

তারপর:

```text
Next.js
```

সবচেয়ে গুরুত্বপূর্ণ mental model হলো:

> **JavaScript দিয়ে আপনি browser-কে কী করতে হবে বলেন। React-এ আপনি UI কেমন হওয়া উচিত সেটা describe করেন, আর React update করার কাজটি manage করে।**

আপনার বর্তমান JavaScript শেখার stage অনুযায়ী, এখনই React syntax মুখস্থ করার চেয়ে **JavaScript fundamentals + `map`, destructuring, spread operator, async/await এবং DOM** ভালোভাবে বোঝা বেশি গুরুত্বপূর্ণ। এগুলো শক্ত হলে React অনেক সহজ মনে হবে।
